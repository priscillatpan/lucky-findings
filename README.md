# Lucky Findings

i want to build building a nature/outdoor quest app, where I'm giving myself daily quests to: get me outside, complete a simple creative task in <5 minutes (you should generate these, but let's review the type of stuff here), keep myself accountable by having to snap a photo for each one. want it to feel like a whimsy field journal that's casual, warm. light or sage green as the main color, cream/paper background, maybe a soft orange accent (but i want to work on the color scheme separately). 

cute font (that i can search for), simple readable body text. rounded, tactile UI — buttons/cards should feel like stickers or stamps, not flat digital rectangles. I'm gonna upload my own hand-drawn badges and icons (starting with a clover logo) so just leave clean placeholder spots for those, don't generate your own art. set this up as a proper design system so it carries across all my screens and lets work on the designs first
